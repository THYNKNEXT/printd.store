# The Printd Store - B2B website draft

Open `index.html` to review the draft. It is a three-page, responsive B2B website:

- `index.html` - concise value proposition, service categories, Why Printd and project flow
- `about.html` - MANIFOLD GLOBAL ENTERPRISES + SIVA SAI ENTERPRISES collaboration story
- `services.html` - detailed product and service categories
- `contact.html` - Chat with us, call, email, local-presence options and a draft enquiry form

## Confirmed claims used

- The Printd Store is jointly created by MANIFOLD GLOBAL ENTERPRISES and SIVA SAI ENTERPRISES.
- The source portfolio supports customized gifts, corporate merchandise, T-shirts, mugs, printing, stationery, branding materials and promotional products.
- The businesses are represented as registered with GeM, CFMS and PFMS, with eligibility for specific procurement routes explicitly left to be confirmed per project.
